SIGNING FINGERPRINT NOT YET PUBLISHED

APK signature verification

The Build 74 release notes state that the APK is signed with the project's permanent release signing key. The signing certificate's SHA-256 fingerprint has not yet been independently verified and published on this page, so no certificate fingerprint is claimed here.

Technical users can inspect a downloaded APK with the Android SDK Build Tools command:

apksigner verify --print-certs LiveStagix_beta.apk

To establish publisher continuity, compare the reported certificate fingerprint with a value obtained through a separate trusted channel, such as the Play Console app-signing certificate. A signature check without a trusted comparison fingerprint does not independently identify the publisher.
