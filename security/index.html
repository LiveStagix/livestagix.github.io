How to verify an APK yourself

With Android SDK Build Tools installed, run this command against the downloaded APK:

apksigner verify --print-certs /path/to/downloaded.apk

Compare the signer's SHA-256 fingerprint with the trusted certificate shown above. A changed fingerprint must be investigated before installing. A valid signature confirms the file has not changed since it was signed; it does not prove the app is free from malicious behaviour.

VirusTotal checks are point-in-time signals. Keep Google Play Protect enabled; it can check apps installed from outside Google Play too. You can also install LiveStagix from Google Play.
