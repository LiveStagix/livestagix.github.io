How to verify a downloaded APK yourself

Run this command with Android SDK Build Tools installed:

apksigner verify --print-certs LiveStagix_beta.apk

Compare Signer #1 certificate SHA-256 digest with the trusted certificate fingerprint above. The APK signature must verify and the certificate fingerprint must match. A changed fingerprint is not automatically proof of malware, but it must be investigated before installing.

A valid signature confirms that the APK was signed by the matching release key and has not been modified since signing. It does not establish that the app is free from malicious behaviour.
