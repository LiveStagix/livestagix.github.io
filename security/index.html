SIGNING CERTIFICATE VERIFIED — BUILD 74

APK signature verification

The certificate fingerprint below was extracted from the Build 74 APK supplied for verification. The APK's SHA-256 exactly matches the digest published in the official GitHub release metadata, and its APK Signature Scheme v2 signer signature was cryptographically verified.

Certificate SHA-256 fingerprint

49:19:B3:24:92:85:91:8C:4C:4C:89:4E:8B:46:B1:71:3A:E1:03:20:1F:D5:36:D3:37:02:1D:5C:7F:20:5E:78

To check a downloaded APK yourself, run this Android SDK Build Tools command:

apksigner verify --print-certs LiveStagix_beta.apk

Compare the value shown for Signer #1 certificate SHA-256 digest with the fingerprint above. Letter case and colon separators may differ. This fingerprint identifies the signing certificate used by the verified Build 74 file; unexpected changes in later releases should be investigated before installing.

This verification confirms the file's signing identity and integrity, not that the app is malware-free. Google's guide to APK signing fingerprints.

INDEPENDENT SCAN NOT LINKED

Malware scan status

This page does not currently publish a VirusTotal scan report for the exact Build 74 APK. That is an absence of a published scan result—not a malware detection, and not a clean scan verdict.

You can look up the exact file by its SHA-256 digest on VirusTotal. Confirm that the report's hash matches the checksum above before interpreting any results.

Multi-engine scan results are point-in-time signals, not a guarantee that software is completely safe. Android users should also keep Google Play Protect enabled; it checks apps from Google Play and can also check apps installed from other sources.

Distribution guidance: use this website and the linked LiveStagix release repository for the direct APK. The Google Play link is currently a closed-test route and is available only to eligible testers; it should not be mistaken for a public production listing. The release repository describes LiveStagix as proprietary software, with source code and build tooling maintained separately.
